# Architecture

Offline authoring enumerates restricted support sequences, realizes compact recipes and validates connected ordered blocks. A continuous-time reference solver is independent of the separate 20 ms race integrator. Both treat a gate as open on [0,2500) and closed on [2500,4000), with nanosecond-scale phase normalization at floating-point boundaries. The shipped diagnostic selects prevalidated bank data; it does not invent courses during play.

The domain engine owns legal actions, all three entrants, fixed AI personalities, rank, clean transitions and nonrecursive checkpoints. Session owns the monotonic journey, three immutable queued courses, six-family/fork bags, recent-12 structural/recent-64 normalized-layout guards, compact 64-record LRU, teaching records, serialized save acknowledgements and typed reward fixtures. Bag feasibility lookahead prevents an unavailable family/fork pairing. Replay origin survives reload and cannot clear the journey again.

Snapshots identify immutable course data by ID/content hash; checkpoints share the catalog instead of duplicating graphs. Newer/corrupt/unknown data and operational read failures cannot be overwritten. A late acknowledgement cannot clear newer dirty progress. Host, menu and ad pauses compose. The standalone diagnostic has a single pointer owner and semantic DOM controls. It has no production SDK, audio, external requests or analytics.

The pinned canonical shared foundation is retained as a reference in source; it is not executed by this standalone diagnostic. Production direct YouTube integration, final graphics, native/device validation and host certification are outside the completed evidence scope. A Playgama wrapper is not a substitute for the direct YouTube runtime contract.
